# Architecture Decision Records (ADRs)

## DEC-001 — Static-artifact serving by default (ADR-1) (2026-09-30)
**Context:** Production hosting for API.
**Decision:** Static-artifact serving by default. The deployed API loads model + `geo_layers.npz` + precomputed JSON/Parquet from disk. No database in production.
**Why:** Free Postgres expires; a DB adds failure modes for zero demo value.
**Decided by:** Executor (Plan ADR-1)

## DEC-002 — PostGIS is optional, local-only (ADR-2) (2026-09-30)
**Context:** Spatial query engine.
**Decision:** PostGIS is optional, local-only for analysis convenience. Everything the API needs is exported as files.
**Why:** Keeps prod simple and free.
**Decided by:** Executor (Plan ADR-2)

## DEC-003 — Serving stack lean dependency list (ADR-3) (2026-09-30)
**Context:** Container image memory budget.
**Decision:** Serving stack excludes geopandas, shapely, osmnx, shap, mlflow, matplotlib. Allowed: numpy, pandas, scikit-learn (BallTree), lightgbm, fastapi, uvicorn, pydantic.
**Why:** Fits a 512 MB container; faster cold start.
**Decided by:** Executor (Plan ADR-3)

## DEC-004 — Shared NearestIndex class (ADR-4) (2026-09-30)
**Context:** Spatial distance calculations in training and serving.
**Decision:** Distances use one shared class (`NearestIndex`, haversine BallTree) for both training and serving. Roads are densified to points every ≤ 50 m at build time.
**Why:** Guarantees training/serving parity; max distance error ≈ 25 m.
**Decided by:** Executor (Plan ADR-4)

## DEC-005 — Natural log target and native LightGBM contributions (ADR-5) (2026-09-30)
**Context:** Price modeling and explainability.
**Decision:** Target = natural log of price (`np.log`, not `log1p`). Explanations = LightGBM `predict(pred_contrib=True)`; effects reported as exact multiplicative factors `exp(contribution)`.
**Why:** Additivity in log space makes the factor breakdown exact.
**Decided by:** Executor (Plan ADR-5)

## DEC-006 — Best model family expected: LightGBM (ADR-6) (2026-09-30)
**Context:** Model selection.
**Decision:** If another family wins by a meaningful margin, keep LightGBM as the served model only if the loss is < 2% MAPE relative, otherwise update ADR-5's explanation method.
**Why:** Native contributions keep serving light.
**Decided by:** Executor (Plan ADR-6)

## DEC-007 — Spatially grouped cross-validation (ADR-7) (2026-09-30)
**Context:** Model validation strategy.
**Decision:** Model selection uses spatially grouped CV. Random-split scores are reported only for comparison.
**Why:** Random splits leak neighbourhood information.
**Decided by:** Executor (Plan ADR-7)

## DEC-008 — Conformal calibration on out-of-fold residuals (ADR-8) (2026-09-30)
**Context:** Prediction uncertainty estimation.
**Decision:** Intervals via conformal calibration on out-of-fold residuals (log scale), checked on the untouched test set.
**Why:** Distribution-free, simple, verifiable.
**Decided by:** Executor (Plan ADR-8)

## DEC-009 — Numbers ledger (ADR-9) (2026-09-30)
**Context:** Quantitative claims in documentation.
**Decision:** `docs/RESULTS.md` is generated by `make report`; docs quote from it only.
**Why:** Prevents stale/invented numbers.
**Decided by:** Executor (Plan ADR-9)

## DEC-010 — Raw third-party data publishing policy (ADR-10) (2026-09-30)
**Context:** Open source repository and data redistribution.
**Decision:** Raw third-party data is not committed if its licence forbids redistribution; the repo ships download scripts + a data card instead.
**Why:** Legal safety.
**Decided by:** Executor (Plan ADR-10)

## DEC-013 — Hosting Shortlist and Memory Budget Plan (2026-09-30)
**Context:** Verification of hosting free tiers and resource constraints for production deployment.
**Verified Hosting Targets (as of 2026-09-30):**
- **Frontend Host:** Vercel (Primary, static SPA on global CDN) / Cloudflare Pages (Backup).
- **Backend API Host:** Render Free Web Service (Primary: 512 MB RAM, 0.1 CPU, spins down after 15 min idle, 750 free hours/month).
- **Backup API Host:** Hugging Face Spaces (Docker CPU Basic) / Fly.io / Railway.
**Memory Budget & Go/No-Go Rule:**
- Serving container RSS target: `< 400 MB` (benchmarked in M9 and API7).
- If container RSS ≥ 400 MB: Refactor precomputed structures or escalate to Owner for paid always-on tier (Render Starter ~$7/mo).
- Lean serving image enforced: No geopandas, shap, shapely, osmnx, or mlflow in `requirements-api.txt`.
**Decided by:** Executor (Task R6)
